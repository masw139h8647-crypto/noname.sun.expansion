#无名杀扩展(noname.sun.expansion)

基于无名杀编写的原创武将

##介绍

自行将代码复制于无名杀便可游玩。我不太懂如何才能直接导入武将，所以请自行打开txt文件复制，再打开无名杀点击扩展，制作扩展，编辑技能，然后所有技能各自第一行作为名称，剩余行复制于编辑代码，复制README技能描述。复制完成后，在编辑武将中点创建武将输入武将资料，随便带入一个图作为武将头像，添加技能再于此扩展点对应技能添加（如果没出现复制的技能，先点一个其他武将再点回此扩展），做完一切后点保存，再点立刻重启

##技能概述

斡衡：监测全场体力及手牌，连锁摸弃

御麾：令符合条件的角色发动一次斡衡

连营：开局及失去对应花色摸牌并展示

决死：弃牌印酒，手牌用光摸牌印决斗

流矢：使用非因使用而失去的非装备牌

天垒：被杀或濒死摸二重铸再受伤加一

严备：每轮都可以白印一张任意基本牌

狭威：用牌或被指定摸视情况张标记牌

穷技：失去标记牌放着于结束弃等量牌

##技能描述

吴 孙权 三体力

斡衡：当一名角色的体力值变化后，若其体力值与你相同，你可以令一名手牌数与你相同的角色：1.摸一张牌；2.弃一张牌，然后其须对一名除其以外的角色发动一次摸弃牌数为上次此技能使角色摸弃牌数加一且选项不同的“斡衡”

御麾：主公技，出牌阶段限一次，你可以令一名其他吴势力角色发动一次"斡衡"

吴 陆逊 三体力

连营：锁定技，游戏开始时，你摸一张牌并展示之，然后你下次失去该花色的手牌时，重复此流程

魏 庞德 三体力

决死：你可将手牌弃至当前体力值，视为使用一张【酒】。然後於本回合內下次你使用牌結算後沒有手牌時，将手牌摸至当前体力值，并可视为使用一张【决斗】。

流矢：当你非因使用失去非装备牌时，你可使用之。

魏 郝昭 四体力

天垒:当基本牌对你生效时,或进入濒死状态时,你可以令你本轮受到的伤害+1,并摸两张牌,然后可重铸任意张牌,你以此法获得的手牌于回合结束时弃置

严备：每轮限一次，你可以视为使用一张任意基本牌

群 桥蕤 五体力

狭威：当你使用一张牌时，或被使用的牌指定时，你可以摸三张牌并称为“威”。
你每满足以下一项，则此技能摸牌数-1：
本回合发动过此技能
手牌中的“威”多于非“威”
武将牌上的“威”多于体力值

穷技：锁定技，当你的“威”牌进入弃牌堆时，将之置于武将牌上。一名角色的回合结束时，你弃置x张牌(不足则全弃)，然后移去等量张武将牌上的牌。(x为你武将牌上的牌数)
